# Pitfalls

What sessions **measured** about the environment, the tools and the platform: a trap that
cost time once and should not cost it twice. One trap per file, named by its date and
subject: `2026-02-03-pooler-user-carries-the-role.md`.

```markdown
# The pooler's user name carries the role

Measured: 2026-02-03.

## Symptom

What was seen, with the exact message.

## Cause

What was found, and how it was proved.

## Remedy

What to do. If it changes how sessions work, the one-line rule that went to `AGENTS.md` or
to a path rule.

## Supersedes

An older pitfall this one makes false, if any. Then delete the older file.
```

- A pitfall that stops being true is **deleted**, not annotated: a stale warning is obeyed as
  faithfully as a true one.
- A limit of the instrument is written here, with its date. It is not written as a rule of
  the project.
- The folder listing is the index. No index file: it would be edited by every branch.
