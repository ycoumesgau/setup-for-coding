# setup-for-coding

A starting point for building software with coding agents: the working contract an agent loads
in every session, the guards that keep that contract honest, and the knowledge needed to make
the first decisions of a new product.

It is distilled from production codebases built almost entirely by agents, including what went
wrong in them.

**Status: being written.** The first usable version ships as a Claude Code plugin whose
`/kickoff` command sets up a new repository.
